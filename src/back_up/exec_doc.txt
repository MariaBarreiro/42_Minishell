Objetivos:
--------------------------------------------------------------------
Contar quantos comandos existem na lista

Se apenas 1:
se builtin → exec builtin sem fork
se externo → fork + execve normal

Se mais de 1:
pipes
fork para cada comando
redirecionamentos + execve
wait pelos filhos

--------------------------------------------------------------------
Fluxo:

< redir_in

Para cada arquivo em cmd->input[i]:

fd = open(file, O_RDONLY)
dup2(fd, STDIN_FILENO)
close(fd)

> redir_out
fd = open(file, O_WRONLY | O_CREAT | O_TRUNC)
dup2(fd, STDOUT_FILENO)
close(fd)

>> redir_append
fd = open(file, O_WRONLY | O_CREAT | O_APPEND)
dup2(fd, STDOUT_FILENO)
close(fd)

<< heredoc

Se cmd->heredoc > 0:

dup2(cmd->heredoc_fd, STDIN_FILENO)
close(cmd->heredoc_fd)

-------------------------------------------------------------------------
Se houver N comandos:

cria N−1 pipes:
int pipes[n_cmds - 1][2];


Para cada comando i:

se não for o primeiro:
dup2(pipes[i-1][0], STDIN)


se não for o último:
dup2(pipes[i][1], STDOUT)

E fechar todos os descritores que não são usados.

-------------------------------------------------------------------------

execve(cmd->args[0], cmd->args, global_sh->env);

Se não tiver / no comando, resolva com PATH:

char *path = find_in_path(cmd->args[0], global_sh->env);
